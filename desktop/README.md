# Apex desktop app

A native Windows window for the Apex dashboard. It starts the dashboard server itself on a free loopback port and shows it in its own window with the Apex icon. Closing the window hides it to the notification area (tray) with the server and agents still running; **Quit Apex** in the tray menu stops the server and every agent it started. Sessions are saved by Pi and can be resumed from the sidebar next time.

The setup program (`apex-setup-<version>.exe`) installs it with its own Electron as **Apex Desktop** in the Start menu and, by default, on the desktop. The steps below are for running it from a Git checkout.

## Use

    bun install                          # adds Electron
    bun node_modules/electron/install.js # downloads the Electron binary if the install skipped it (always needed after --ignore-scripts)
    bun run desktop:shortcut             # creates "Apex" in the Start menu and on the desktop
    bun run desktop                      # or start it from a terminal

The shortcuts run this checkout, so `git pull` updates the app. Re-run `bun run desktop:shortcut` if you move the folder.

## Behaviour

- One window: starting Apex again shows and focuses it, also when it is hidden in the tray.
- Closing the window hides it to the tray (a one-time balloon says so). Click the tray icon to open it again; right-click for **Open Apex**, **Check for updates** and **Quit Apex**. Signing out of Windows closes it for real.
- The version is in the title bar, the tray tooltip and menu, and the dashboard sidebar; a Git checkout shows "(development checkout)".
- Updates: a few seconds after it starts, the installed app asks GitHub for the newest release. If that is newer and not skipped, it asks **Update now / Later / Skip this version**. Update now downloads `apex-setup-<version>.exe`, verifies it against the release's `SHA256SUMS`, quits Apex (running agents stop; sessions stay resumable), runs the setup silently over the install and opens Apex again. Failures at start stay silent; **Check for updates** in the tray menu reports every outcome. A Git checkout is never updated (use Git). `APEX_NO_UPDATE_CHECK=1` turns the start-up check off; a private repository needs `GH_TOKEN` or `gh auth login`, as for `apex update`.
- Sign-in pages and links in answers open in your default browser; the window only ever shows the dashboard.
- Bun comes from PATH (1.4.3 or newer); set `APEX_BUN` to a specific `bun.exe` to override.
- If the server fails to start, the window shows its error output and a Retry button.
- Window size and position are kept in `%APPDATA%\Apex Desktop\window.json`.

## Checks

    bun test tests/desktop-shell.test.mjs tests/dashboard-desktop.test.mjs
    bun run smoke:desktop       # opens the real window briefly, checks it, closes it to the tray, quits, confirms the server exited;
                                # then starts with a missing Bun and checks the failure page and Retry

The icon is generated by `bun scripts/make-desktop-icon.mjs`; replace `desktop/icon.ico` with your own if you like.
