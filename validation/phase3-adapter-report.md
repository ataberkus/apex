# Phase 3 Python adapter and planner

Implemented nine pure feature flags (`cost,checkpoints,review,plan,remember,skills,safety,report,resume`) with explicit `all`, default off and rejection of unknown, duplicate or non-string values. Selected Harbor Apex variants require the selected Muse model and xhigh; effective-provider overrides remain restricted to OpenRouter. The adapter adds `--apex-features FLAGS --apex-eval` before Pi arguments, preserving the literal task, original evaluator timeout and existing no-feature command string.

The planner adds `feature_flags` as its final optional parameter and exposes `--feature-flags`. Prepared variants retain a distinct configuration label and explicit eval-mode annotation. Stock Pi cannot select these flags. Plans remain JSON-only preparation; the existing spend/free-only guard can block even a zero-cost estimate. No execution or reservation option was added. Structural validation now compares the Phase 3 registry against the same nine Python flag names.

Test-first evidence: before implementation, focused discovery failed with `ModuleNotFoundError: evals.feature_flags`. After implementation, all **16 focused tests passed** in 0.086 seconds. Coverage includes exact flags, invalid arguments, all three phase prefixes, literal task preservation, default command preservation, model/thinking/provider refusals before environment access, options schema validation, stock control refusal, free-only refusal, final-parameter positional compatibility and the preparation-only CLI. Tests used the installed source-pinned Harbor Python runtime with a whitelisted environment (`PATH`, locale variables, public Node executable path), `PI_OFFLINE=1` and offline npm configuration pointing at loopback port 9. Container commands were only captured by a fake environment; no commands were executed there.

New provider, auth, credential, network, container and benchmark calls: **0**. New spend: **$0**. Global structural checks and regression suites are delegated to the root coordinator; this report covers only the owned focused Python tests. Flags remain default off and empirical pass rate, token/cost effects and model routing accuracy remain unmeasured. The eval marker is explicit feature-variant configuration, never dataset/task detection. The root extension must enforce eval learnings denial before filesystem I/O.
