## Native integration evidence

The gate loaded the actual extension factories into Pi's SDK, initialized native registered wrappers, executed local read/outline/search/edit/patch/Bash operations, checked deferred discovery and the selected classifier-free codemode, and persisted/reopened observation edits. Codemode parsed **20,481 bytes of nested JSON into a 4,096-item count** without shaping its program input. Native manual compaction cancelled before auth/inference.

Controlled shape fixture: **38,390 → 6,536 hook-visible bytes**. Synthetic persisted-mask fixture: **26,600 → 177 bytes**. These are local context-size observations, not provider tokens, cost savings or benchmark results. The masking fixture is expressly synthetic; it does not estimate the fraction of real observations eligible for masking.

The SDK fixture blocks credentials, auth, inference, network and ambient discovery. Test-only boundaries suppress native package discovery and one allowNetwork:false virtual-model availability refresh; explicit physical Muse/xhigh selection avoids authenticated default selection. Top-level result hooks are invoked through the actual runner after registered definition execution; nested execution remains native. Fault modes fail the gate for missing cancellation, ambient discovery or lost nested metadata. Full isolation is not a general runtime sandbox claim.
